# UI assets

- `icons.svg`: selected outline glyphs from **Reicon 1.2.5** (npm package `reicon`),
  author devchauhan, package license MIT; https://github.com/dqev/reicon.
  Vendored locally so controls work without external scripts or internet access.
- `filmstrip.jpg`: ten frames extracted from the local source clip at 0, 7.5,
  15, 22.5, 30, 37.5, 45, 52.5, 60, and 67.5 seconds. No generated match imagery.
